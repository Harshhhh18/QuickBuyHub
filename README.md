# QuickBuyHub

An online clothing e-commerce store with responsive design and interactive shopping features.

**Full Stack Web Application** | HTML, CSS, JavaScript, PHP

---

## 🛍️ Project Overview

QuickBuyHub is a functional e-commerce platform for browsing and purchasing clothing items. The application features a responsive design that works seamlessly on desktop and mobile devices, with an interactive shopping cart and customer contact system.

---

## ✨ Features

- **Product Browsing** - Browse and view clothing items
- **Shopping Cart** - Add/remove items, manage purchases
- **Contact System** - Customer inquiry and feedback form
- **Responsive Design** - Works on all devices (mobile, tablet, desktop)
- **Interactive UI** - Smooth user experience with JavaScript
